First release. The show.fm player as the `<showfm-player>` custom element (with the `<podcasterplus-player>` alias), imported unchanged from the show.fm app. It ships as a classic script (`dist/cdn/v1.js`, the file served as `/player/v1.js`), an ESM entry that registers the elements, and Svelte 5 source at `@showfm/embed/svelte`. It also includes the height contract constants, a Custom Elements Manifest and JSX typings for React, Preact and Solid.
